# Chert Varve

**Varve** is the successor to **Floc**: the same Lato + Merriweather pairing,
self-hosted, set at a 700px reading measure with an OS-following dark mode.
A varve is one year's pair of sediment layers, one light and one dark.

Config this theme reads from `chert.yaml`, beyond chert's defaults:

- `site.newsletter`: `{action, popup_url, heading, tagline, button, placeholder}`
  renders the footer signup form (Buttondown-shaped). Omit the key for no form.
- `rel: me` on any `primary_links`/`secondary_links` entry emits `rel="me"`.
